# rime-quad

切り替えずに、日本語やスペイン語、そういう言語を混ぜて入力したいのです。

## Features

- [latin.dict.yaml](./latin.dict.yaml)

    - 字母混输：西班牙语、匈牙利语、德语、葡萄牙语、法语、其他
    - 特殊功能：`[?` 自动上屏为 `¿`，`[!` 自动上屏为 `¡`

- 中日混输

    - 平片转换：输入框按 `F9` 键
    - 简日转换：输入 `]` 后使用中文双拼选择日语汉字

    - 双拼映射：小鹤双拼
    - 笔画辅助：输入框按 `Tab` 键

- [quad-c.yaml](./quad-c.yaml) - 热键绑定

    - 切换输入：输入框按 `\` 键
    - 简繁转换：`Ctrl+Shift+J`
